# Delta One

Python tools around Delta One products: dividends, decrement indices and index replication.

| Project | Content |
|---|---|
| [implied_dividends](implied_dividends) | Implied dividend curve from put-call parity, compared with dividend futures |
| [decrement_index](decrement_index) | Fixed-point and percentage decrement indices built from an NTR index |
| [index_replication](index_replication) | Physical replication with quarterly rebalancing, tracking error and turnover |

Every script runs on synthetic data with `--demo`. Real market data stays local and is never committed. Code comments are in French.
